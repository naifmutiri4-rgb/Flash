# فلاش ستور المالية

تطبيق مالي خاص لمتجر فلاش ستور على سلة. يحسب المبيعات والتكاليف والرسوم والإعلانات والصافي لحظيًا، ويربط سلة وإعلانات تيك توك ومزودي الخدمات (دكتور دعم و smmcpan).

## كيف يشتغل

التطبيق صفحة واحدة (`index.html`) تشتغل كـ **Artifact داخل Claude**. Claude يعطيها:

- **قاعدة بيانات** خاصة (الطلبات والمصاريف والإعدادات والنسخ الاحتياطية).
- **الموصلات**: سلة (Salla MCP)، تيك توك (TikTok for Business)، والمزودين (Flash Suppliers).

برا Claude الصفحة تنفتح، بس ما تقدر تقرا البيانات ولا الموصلات.

لا يوجد في هذا المستودع أي مفاتيح أو كلمات مرور أو بيانات عملاء. المفاتيح محفوظة في Cloudflare Secrets، والبيانات في قاعدة بيانات التطبيق داخل Claude.

## الملفات

| المسار | وش فيه |
|---|---|
| `index.html` | التطبيق كامل جاهز للنشر |
| `src/app.css` | التصميم (الوضع الداكن والفاتح، الخط، الجداول) |
| `src/body.html` | هيكل الصفحة: القائمة والشريط العلوي وشاشة الدخول |
| `src/app.js` | كل المنطق: الحسابات، المزامنة، الصفحات، التنبيهات |
| `build.py` | يجمع الأجزاء الثلاثة في `index.html` |
| `connector/worker.js` | موصل المزودين على Cloudflare Workers (قراءة فقط) |
| `connector/test*.mjs` | اختبارات الموصل |

## التعديل

1. عدّل الملفات داخل `src/`.
2. شغّل `python3 build.py` عشان يتحدث `index.html`.
3. انشر `index.html` على نفس رابط الـ Artifact في Claude.

## الموصل (Cloudflare Worker) — نسخة 2.1

- **الأسرار:** `DRD3M_KEY`، `SMMCPAN_KEY`، `CONNECTOR_TOKEN`.
- **السجل التلقائي:** ربط KV باسم `FLASH_KV`، و Cron Trigger كل 15 دقيقة. يسجّل الشحن والاستهلاك اليومي وتغيّر أسعار الخدمات.
- **الأدوات (كلها قراءة):** الرصيد، الخدمات وأسعارها، حالة الطلبات، سجل الشحن، الحركة اليومية، تغيّر الأسعار، حالة السجل.
- **إشعار تيليجرام (اختياري):** الأسرار `TELEGRAM_TOKEN` و `TELEGRAM_CHAT_ID` و `HOOK_TOKEN`، ورابط الويب هوك `/hook/<HOOK_TOKEN>`.
- الموصل ما يقدر ينشئ أو يلغي طلبات، فحتى لو انكشف رابطه ما يصرف شي.

الاختبارات: `node connector/test.mjs` و `node connector/test2.mjs`.
