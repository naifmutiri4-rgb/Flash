# معاينة فلاش ستور (GitHub Pages)

نسخة ثابتة من صفحات flashstore-ksa.com الحقيقية بالتصميم الجديد (`salla/v4/flash-malak.css` + ترتيب مسودة «ترتيب ذكاء»).
- `index.html` الرئيسية، و`views.html` … `explore.html` صفحات المنتجات.
- `preview.html` إطار جوال مع أزرار للتنقل بين الصفحات.

تتولّد من جديد بـ `node salla/preview/snapshot.js` ثم نسخ `salla/preview/site/` لهنا.
السلة والدفع ما يشتغلون هنا (نسخة ثابتة)، يشتغلون في المتجر نفسه.
