# ثيم ملاك (Malak) لمنصة سلة: مرجع الكلاسات والهيكل

المصدر: ثيم ملاك إصدار 1.175.0، مأخوذ من متجر حي على سلة.
ملف CSS الكامل للثيم: https://cdn.assets.salla.network/themes/1034648396/1.175.0/app.css
CSS الكلاسات المستخدمة فعلياً: https://naifmutiri4-rgb.github.io/Flash/live/malak-used.css

طريقة القراءة:
- كل سطر في الهيكل = عنصر: tag#id.class1.class2 "نص مختصر"
- المسافة في بداية السطر = مستوى العنصر داخل اللي فوقه
- "… (+N مثله)" = فيه N عناصر مكررة بنفس الشكل
- العناصر اللي تبدأ بـ salla- هي مكونات جاهزة من سلة (Web Components)
- كلاسات s- تخص مكونات سلة، وباقي الكلاسات (store-header, angel-, product-…) من الثيم نفسه
- الثيم يستخدم Tailwind (flex, gap-4, md:..., إلخ) مع كلاساته الخاصة
