# فلاش ستور — نظام التصميم v4 (Dark Luxury Tech)

## المنتج
متجر آلي لخدمات تيك توك في السعودية (مشاهدات، لايكات، شير، حفظ، و5 باقات). الطلب يحتاج رابط المقطع فقط، والتنفيذ آلي بعد الدفع، والتعويض حسب سياسة المتجر. منصة سلة، ثيم ملاك، عربي RTL. ملاك يسمح بـ CSS مخصص فقط (بدون JavaScript).

## الألوان
| الدور | اللون |
|---|---|
| أساسي (أزرار، تمييز) | `#FC9E01` |
| أساسي فاتح (hover، تدرج ذهبي) | `#FFC04D` |
| أساسي غامق | `#C77A00` |
| خلفية | `#111111` |
| خلفية ثانوية (بطاقات) | `#1E1E1E` |
| حدود | `#343434` |
| نص | `#FFFFFF` |
| نص ثانوي | `#B8B8B8` |

قاعدة: البرتقالي للفعل والقرار فقط (زر، اختيار، رقم مهم). كل الباقي رمادي/أبيض.

## الخط
خط المتجر الحالي PingAR (من سلة، بدون تحميل خط إضافي). صور المنتجات: Readex Pro (مضمّن في الصورة نفسها).
- عناوين الأقسام 24–32px وزن 900، أسعار 17–34px وزن 900 بأرقام متساوية العرض.

## الأشكال
- زوايا: بطاقات 16–18px، أزرار 12–14px، شارات 8px.
- أزرار اللمس ≥ 44px، أزرار الشراء 52–54px.
- ظل واحد فقط: توهج برتقالي خفيف خلف أيقونة الخدمة في الصور.

## الحركة
CSS فقط: تغيّر لون الزر/الحد 150ms، ضغط الزر scale(.98). يتوقف كل شيء مع «تقليل الحركة».
ما فيه حركات دخول للأقسام (تثقّل وتزحزح الصفحة).

## صور المنتجات (1080×1080)
- نظام واحد، تكوين خاص لكل منتج:
  - الباقات: رقم المشاهدات هو البطل (2K → 20K) داخل حلقة مستوى (عدد الأقواس المضيئة = ترتيب الباقة)، و3 أرقام تحت (لايك، شير، حفظ).
  - الخدمات: أيقونة الخدمة كبيرة + الاسم بهايلايت + نقش خلفية خاص (دوائر للمشاهدات، قلوب، أسهم، علامات حفظ). بدون كميات.
- الزاويتان العلويتان فاضيتان لشارات الثيم (الخصم والتقييم).
- «الأكثر طلباً» = الأكثر مبيعاً آخر 90 يوم في تقارير سلة (بكج التوفير).

## ثبات الصفحة (CLS)
أقسام HTML وقوائم المنتجات وخيارات المنتج في سلة تتحمّل بعد الصفحة، فالـ CSS يحجز مكانها مسبقاً.
لو تغيّر محتوى قسم أو انضاف قسم جديد للرئيسية، تتحدّث أرقام `min-height` في `flash-malak.css` (القسم 5).
