# فلاش ستور v4 — التسليم

كل التعديلات على نسخة ملاك غير المنشورة **«ترتيب ذكاء»** (version 1470549421). المتجر المنشور ما تغيّر.

## v5 (الحالي) — الرئيسية
- أول شاشة = عنوان قسم الباقات (يرسمه سلة من السيرفر) + الباقات مباشرة. صار هو LCP بدل صور المنتجات.
- العدّاد (بكج التوفير): أرقام تدور مع التمرير، CSS فقط (scroll-driven)، وتتوقف مع «تقليل الحركة».
- خدمة مفردة: قائمة أسعار بخطوط فاصلة بدل كروت. كيف تطلب: خط زمني. ليش فلاش: قائمة.
- الكود: `../v5/build_home.py` (HTML بكلاسات) + القسم 12 في `flash-malak.css`.
- قياس محاكاة على الرئيسية الحقيقية (جوال، 4G، معالج ×4): **LCP 5.98 ← 0.82 ث**، **CLS 1.68 ← 0.013**.
- تأكّدت إن قسم «محتوى HTML» في سلة يشيل `<style>` و`<script>`، فالتصميم والحركة لازم من «CSS مخصص».

## اللي انطبّق في المسودة (عن طريق سلة مباشرة)
- إعدادات الثيم: ألوان الهوية (#111111 / #1E1E1E / #343434 / #FC9E01)، إخفاء الوسوم و«متوفر».
- الرئيسية بالترتيب: البداية (مع الأكثر طلباً) ← الباقات ← خدمة مفردة ← كيف تطلب + ليش فلاش ← آراء العملاء ← الأسئلة.
- الأسئلة الشائعة: تصحيح وسائل الدفع (إضافة STC Pay).
