# فلاش ستور v4 — التسليم

كل التعديلات على نسخة ملاك غير المنشورة **«ترتيب ذكاء»** (version 1470549421). المتجر المنشور ما تغيّر.

## اللي انطبّق في المسودة (عن طريق سلة مباشرة)
- إعدادات الثيم: ألوان الهوية (#111111 / #1E1E1E / #343434 / #FC9E01)، إخفاء الوسوم و«متوفر».
- الرئيسية بالترتيب: البداية (مع الأكثر طلباً) ← الباقات ← خدمة مفردة ← كيف تطلب + ليش فلاش ← آراء العملاء ← الأسئلة.
- الأسئلة الشائعة: تصحيح وسائل الدفع (إضافة STC Pay).

## المطلوب منك (سلة ما تعطيني أداة لها)
1. **CSS:** تصميم المتجر ← ملاك «ترتيب ذكاء» ← CSS مخصص ← الصق محتوى `flash-malak.css` كامل (يستبدل القديم).

## جاهز، ينتظر موافقتك (يغيّر المتجر المنشور فوراً)
- `img/*.png` — 9 صور منتجات جديدة.
- `descriptions.json` — أوصاف محدّثة (نفس المعلومات + مقدمة ومتطلبات التنفيذ).

## الملفات
| الملف | وش هو |
|---|---|
| `flash-malak.css` | CSS المتجر كامل (≈ 15KB، بدون خطوط أو JS) |
| `build_home.py` | يولّد أقسام HTML للرئيسية → `home-blocks.json` |
| `images.js` | يولّد صور المنتجات → `img/` |
| `descriptions.py` | يولّد الأوصاف → `descriptions.json` |
| `DESIGN.md` | نظام التصميم |
| `../audit/` | سكربتات الفحص (Playwright) واللقطات قبل/بعد |
