# بوت تحليل الإعلانات (تيليقرام + Claude)

ترسل للبوت تقرير إعلاناتك (لقطة شاشة، Excel، CSV، PDF، أو نص) ويرد عليك بتحليل وتوصيات بالعربي.
يتذكر سياق المحادثة، فتقدر تسأله بعدها: "طيب أي حملة أوقف؟" أو "كيف أنزل تكلفة التحويل؟".

## الإعداد (مرة وحدة)

1. **أنشئ البوت:** في تيليقرام افتح `@BotFather` ← `/newbot` ← انسخ التوكن.
2. **مفتاح Claude:** من https://platform.claude.com ← API Keys ← أنشئ مفتاح (يحتاج رصيد).
3. **رقم حسابك:** افتح `@userinfobot` في تيليقرام وانسخ الرقم (عشان البوت يرد عليك أنت بس).

## التشغيل

```bash
cd telegram-bot
pip install -r requirements.txt
cp .env.example .env    # وعبّي القيم
set -a; source .env; set +a
python bot.py
```

افتح البوت في تيليقرام واكتب `/start`.

## التشغيل الدائم (24 ساعة)

الجهاز اللي يشغّل `bot.py` لازم يظل شغال. خيارات سهلة:
- **Railway / Render:** ارفع المجلد، أمر التشغيل `python bot.py`، وأضف المتغيرات الثلاثة في إعدادات Environment.
- **سيرفر VPS:** شغّله عبر `systemd` أو `screen`.

## الأوامر

| الأمر | الوظيفة |
|---|---|
| `/start` | رسالة الترحيب |
| `/new` | مسح المحادثة والبدء من جديد |

## ملاحظات

- النموذج الافتراضي `claude-opus-5-5`. تقدر تغيّره من `CLAUDE_MODEL` (مثلاً `claude-sonnet-5-5` أرخص).
- إذا تركت `ALLOWED_USER_IDS` فاضي، أي أحد يلقى البوت يقدر يستخدمه ويصرف من رصيدك.
- السجل محفوظ في الذاكرة؛ إعادة تشغيل البوت تمسحه.
